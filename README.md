# 📖 听书助手

一个简洁优雅的在线听书工具，让你可以将任何文本小说转换成语音朗读。

## ✨ 功能特点

- **本地小说**：支持直接上传 TXT 格式的小说文件
- **在线小说库**：预置多本人气小说，无需上传即可听书
- **灵活朗读**：可调节语速、音调、音色
- **章节导航**：自动识别章节，轻松跳转
- **定时朗读**：支持设置朗读时长，适合睡前使用
- **跨平台访问**：支持电脑和手机浏览器

## 🚀 快速开始

### 方法一：直接访问（推荐）

打开网址：https://hsira.github.io

### 方法二：部署自己的版本

如果你想上传自己喜欢的小说，请查看下面的详细教程。

## 📚 使用指南

### 上传本地小说

1. 点击"上传本地小说"区域的"选择文件"按钮
2. 选择你的 TXT 格式小说文件
3. 等待加载完成（自动识别章节）
4. 选择想听的章节
5. 点击"播放"按钮开始听书

### 调节朗读设置

- **音色**：选择不同的语音（需要浏览器支持）
- **速度**：调节朗读速度（0.5-2倍）
- **音调**：调节音调高低（0.5-2倍）
- **定时**：设置自动停止时间（分钟）

## 🔧 从零开始部署自己的听书网站

以下教程专为不懂编程的朋友设计，每一步都有详细说明。

### 第一步：注册 GitHub 账号

GitHub 是一个代码托管平台，我们可以免费使用它来搭建自己的网站。

**操作步骤：**

1. 打开浏览器，访问 https://github.com
2. 点击页面上的 "Sign up" 按钮（注册）
3. 按提示填写：
   - **Email**：填写你的邮箱
   - **Password**：设置密码（至少8位）
   - **Username**：设置用户名（只能使用英文字母、数字和短横线）
4. 点击 "Create account"
5. 可能需要验证邮箱，打开你的邮箱找到验证邮件点击链接即可

> 💡 **提示**：Username 很重要！这就是你网站地址的一部分。建议使用简单的英文名，比如 `zhangsan`。

### 第二步：Fork（复制）本项目

Fork 的意思是把别人的项目复制一份到自己的账号下，这样你就可以修改里面的内容了。

**操作步骤：**

1. 确保你已经登录 GitHub 并打开这个页面：https://github.com/hsira/hsira.github.io
2. 点击页面右上角的 "Fork" 按钮
3. 等待几秒钟，页面会自动跳转到你的账号下
4. 现在你看到的就是你自己的项目了，地址栏显示的是你的用户名

### 第三步：上传你的小说文件

**操作步骤：**

1. 在你的项目中找到 `novels` 文件夹（点击进入）
2. 点击右上角的 "Add file" 按钮，选择 "Upload files"
3. 将你的小说 TXT 文件拖拽到上传区域，或点击 "choose your files" 选择文件
   - **注意**：文件夹名称必须是英文，不要有中文
   - 可以创建新文件夹来分类管理不同的小说
4. 填写上传说明（可选），点击 "Commit changes" 按钮确认

> 💡 **提示**：
> - 你可以上传多个文件
> - 建议按章节将大文件拆分成小文件（每500-1000章一个文件），这样加载更快
> - 小说文件名建议使用英文或数字，方便识别

### 第四步：启用网站托管服务

GitHub Pages 是 GitHub 提供的免费网站托管服务，可以把你的项目变成一个网站。

**操作步骤：**

1. 点击项目顶部的 "Settings"（设置）选项卡
2. 滚动页面到 "GitHub Pages" 部分
3. 在 "Source"（来源）下拉菜单中选择 "main" 分支
4. 点击 "Save" 保存
5. 等待 1-2 分钟，你会看到页面上显示一个链接：`https://你的用户名.github.io/你的仓库名`

> 💡 **重要**：保存后不要关闭页面！继续往下看。

### 第五步：访问你的听书网站

1. 复制上一步显示的链接
2. 打开浏览器新标签页，粘贴并访问
3. 如果页面显示 404 错误，等待 2-3 分钟后再试
4. 成功打开后，你就能看到自己的听书网站了！

> 💡 **提示**：首次访问时，需要选择你的小说文件才能听书。

## ❓ 常见问题

### Q: 上传的小说文件有大小限制吗？
A: 建议单个文件不超过 10MB。如果小说很大，建议按章节拆分成多个文件。

### Q: 为什么选择章节后内容显示为空？
A: 这说明小说文件的章节格式无法被识别。你可以：
1. 确认文件是 TXT 格式（不是 Word 或 PDF）
2. 检查章节标题格式是否正确（如"第一章"、"第1章"、"第一回"等）

### Q: 如何让网站显示我上传的小说？
A: 在网站上选择"GitHub 仓库小说"，然后从下拉菜单中选择你上传的文件。

### Q: 我能在手机上使用吗？
A: 可以！网站支持电脑和手机浏览器。手机访问时请保持屏幕常亮，否则可能会息屏停止播放。

### Q: 如何让朋友也能访问我的网站？
A: 只需要把网站链接分享给他们即可。例如：`https://zhangsan.github.io/hsira.github.io`

### Q: 为什么播放按钮点了没反应？
A: 可能是：
1. 浏览器不支持语音功能（尝试使用 Chrome 或 Safari）
2. 浏览器自动阻止了自动播放，需要先点击页面任意位置
